# スキル回し比較(FFLogs)

FFLogsにアップされたログから、スキル回しを並べて比較するツールです。ブラウザだけで動きます(サーバー不要)。

- **1 取り込み**: FFLogsのレポートURLを貼るだけ(複数可)
- **2 8人比較**: パーティ全員のスキル回し・Active・DPSを同じ時間軸で並べる
- **3 個人フォーカス**: 自分と、同じジョブ(いなければ同じロール)の人を並べ、スキルごとの回数差を表で見る
- ボスの詠唱(コンテンツのタイムライン)とフェーズを上に表示
- 目盛りをドラッグして範囲を区切ると、Active・GCD数・DPS・スキル回数をその範囲で計算し直す
- 比較相手がいなくても、1件のログだけで使える

## 使う人へ

1. 公開ページを開く
2. 「FFLogsでログイン」を押し、FFLogsで許可する(自分のFFLogsアカウントで読みに行くので、APIキーの準備は不要)
3. ログのURLを貼って「読み込む」

ログインしなくても「デモデータで試す」で全機能を確認できます。
読めるのは公開・限定公開(unlisted)のログと、ログインした本人が見られるログです。

## 公開する人へ(最初の1回だけ)

1. このフォルダをGitHubに置き、Settings → Pages で「Deploy from a branch」→ ブランチ `main`、フォルダ `/docs` を選ぶ
   → `https://ユーザー名.github.io/リポジトリ名/` で公開される
2. FFLogsにログインし https://www.fflogs.com/api/clients/ で「Create Client」
   - Name: 自由(ログイン時に利用者へ表示される)
   - Redirect URLs: 公開URL(例 `https://ユーザー名.github.io/リポジトリ名/`)と `http://localhost:5173/` をカンマ区切りで
   - **Public Client にチェックを入れる**(シークレットを使わない方式。シークレットは公開してはいけない)
3. 表示された Client ID を `docs/config.js` に書いて push する(Client IDは公開してよい値)

## 手元で動かす

Node.js 22以上で `start.bat` をダブルクリック(または `node server.mjs`)し、http://localhost:5173/ を開く。
`server.mjs` は `docs/` を配るだけで、データの取得はすべてブラウザ側で行います。

## 数値の見方

| 項目 | 意味 |
|---|---|
| Active | FFLogsが計算した値(FFLogsの与ダメージ画面のActive%と同じ。ダメージを与えていた時間の割合なので、ヒーラーは低めに出る)。範囲を区切ると、FFLogsに問い合わせてその範囲で取り直す(少し待つ) |
| GCD稼働率 | このツールの計算。GCD(ウェポンスキル・魔法)が回っていた時間の割合で、各GCDは「詠唱時間とGCDの長い方」を数える。範囲を変えると即座に再計算。Activeとは計算方法が違うので値は一致しない |
| DPS(FFLogs) | 範囲内の与ダメージ ÷ 範囲の秒数(rDPS/aDPSではない、素のDPS) |
| GCD間隔 | GCDの間隔の代表値(速い方から3割の位置)。スキルスピードの目安 |
| 緑の帯 / 赤い帯 | GCDが回っている時間 / 前のGCDが終わってから1秒以上、次のGCDを押していない所 |

## 仕組み

- `docs/data.js`: FFLogs API v2(利用者本人のログインで呼ぶ)とXIVAPIから取得・整形。取得したログはブラウザ(IndexedDB)に保存し、同じログは2回目から即表示
- スキルの日本語名・GCD/アビリティの区別・アイコンは [XIVAPI](https://v2.xivapi.com/) から取得
- `docs/app.js`: 画面(ビルド不要のHTML/JS)
- `docs/demo.js`: デモデータ

## 制約

- 開幕前の先行詠唱(プリキャスト)は、FFLogsが戦闘範囲に含めない場合は表示されません
- ペット(学者のフェアリー等)の行動は表示していません(本人の指示アクションは表示)
- FFLogs APIの利用量はログインした人ごとに数えられます。長い戦闘(絶など)は1回の読み込みでやや多く使います
